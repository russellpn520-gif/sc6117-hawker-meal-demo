# 餐食照片留出评测

[冻结的样本清单](nutrition5k_holdout.csv) 收录 30 份有食材称重记录的美国加州食堂餐盘。每行保留一张原始顶视照片链接、整盘可食重量及热量、蛋白质、碳水和脂肪参考值。营养标签由原作者依据称重和食物成分表计算。样本冻结时只检查图片链接可访问，尚未运行模型或计算误差。

**来源与改动。** 从 Thames 等人的 Nutrition5k（CVPR 2021）官方深度图测试划分选取餐盘。参考值取自原始 `dish_metadata_cafe1.csv` 和 `dish_metadata_cafe2.csv`，单位为 kcal 和克。本仓库将选中的记录改为统一列名，添加类别与原图链接，保留 `dish_id` 作为 `meal_id`。数据按 CC BY 4.0 使用。[数据说明、作者和划分](https://github.com/google-research-datasets/Nutrition5k) · [许可](https://creativecommons.org/licenses/by/4.0/)

**选样。** 使用 `dish_ids/splits/depth_test_ids.txt` 中有有效参考值的餐盘，按 `SHA256("SC6117-Team1-v1:" + dish_id)` 从小到大排序。从 ID 中的时间戳换算 UTC 日期，每个日期最多取一盘，取满 30 盘后冻结。演示时反复拍摄的鸡饭餐盘继续作为开发样本。

## 课程评测怎么做

1. 加州食堂单列为 `weighed_cafeteria`。另行收集至少 30 份有权使用、未参与调参的课程场景餐食，可各取 15 份新加坡食阁和包装食品。记录包装营养标签、每份净重及实际吃下份数；食阁记录实际可食份量和独立可追溯的营养换算来源。对带骨、未吃完或另加酱料的餐食注明处理方式，所有同盘照片保持在同一分组。
2. 固定用户提示、模型版本和每餐可见的照片、文字和份量线索，分别运行模型直接估计与完整应用流程。参考答案只用于评分。若记录了人工纠正，另列纠正前后结果，记录纠正时新增的信息。
3. 按类别公布总餐数、成功和失败数、两种方案都有输出的餐数。在相同餐盘上报告 kcal、蛋白质、碳水、脂肪四项平均绝对误差。两组单独处理缺失输出，保留未匹配的配料和来源，避免把漏记项当作摄入量为零。
4. 项目报告再选至少 10 个实际失败案例，记录观察结果、误差来源和可复测的改进。此目录目前仅含冻结的样本与参考值。
