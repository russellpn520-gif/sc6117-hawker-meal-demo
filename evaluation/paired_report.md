## 参考值与样本范围

- H01–H06 是新加坡心脏基金会公布的食阁菜照片，营养参考采用 National University Polyclinics 手册中与菜名、单位和能量相符的标准份。两片原味印度煎饼按两份单片累加，两种方法都收到只计算饼的指示。这些照片没有随图的逐盘称重或成分化验。[照片](https://www.myheart.org.sg/techniques/common-food-drinks-sauces-content/) · [标准份参考](https://www.nup.com.sg/docs/nuplibraries/brochures-document/carbohydrate-counting.pdf)
- H07–H14 使用新加坡食品图谱的原始照片和作者记录的可食克数，乘以香港食物安全中心同类点心每 100 g 的四项数值。合照中的指定食物对双方用同一个字母标明。H15 使用图谱的福建肉粽照片，采用新加坡手册的一只肉粽标准值。食谱差异仍可能造成参考误差。这 15 张涵盖主餐和点心，无法代表所有摊位。[图谱、照片和称重附录](https://doi.org/10.3389/fnut.2026.1930409) · [点心营养化验附表 V](https://www.cfs.gov.hk/english/programme/programme_rafs/files/20070227_ra_dim_sum_pdf_full_e.pdf)
- P01–P15 使用带新加坡市场标签的商品记录，按条码配对商品正面和背面标签。双方仅接收相同正面图与指定食用量，答案按背面标签每份或每 100 g 换算。人工核对了标签，遇到结构化字段与标签不一致时采用标签。样本含面包、酸奶、玉米饼、巧克力、谷物、坚果、奶酪与饼干。本组评估已知克数情况下的营养估算。不同市场与年份的配方仍可能有差异。[Open Food Facts 图片说明](https://openfoodfacts.github.io/openfoodfacts-server/api/how-to-download-images/)

## 同图、同提示与费用

两种方法使用同一份 JPEG 字节、同一英语用户问题和份量提示。参考食物名、营养标签、评分表、原文件名和来源链接均不传给模型，图片上原有的品牌、包装正面文字与图谱字母仍然可见。直接提问的系统指令要求给出四个数值。App 使用部署版的识别提示和结构化输出，再走默认食物匹配、克数及查表换算。模拟食用所指定的整份，未利用答案人工修正，也未写入任何用户日记。两组均用 `gpt-5-mini`，每张每组一次，不重试。直接调用记录的版本为 `gpt-5-mini-2025-08-07`；部署版照片模块记录模型别名。

60 次调用全部返回，合计 **50,044 个输入 token，14,039 个输出 token**。按标准非缓存单价每百万输入 $0.25、输出 $2 计算，本次约 **US$0.0406**，约占课程 $16 总额的 **0.25%**。实际账单如有缓存折扣可能更低。此数是本次实验估算，未读取团队账户的累计消费或余额。[OpenAI 定价](https://developers.openai.com/api/docs/models/gpt-5-mini)

## 可复查的失败

| 样本 | 实际自动结果 | 对这张照片的影响 |
| --- | --- | --- |
| H01 干捞云吞面 | 面与配汤均列为未匹配 | 无整餐数值，直接提问则高估了 309 kcal |
| H02 肉碎粥 | 给出含蛋粥的描述，未落到参考项 | 无小计 |
| H03 福建虾面 | 只计入绿豆芽 | 14.4 kcal，对照标准份 522 kcal |
| H04 两片原味印度煎饼 | 饼和蘸汁均未匹配；直接模型给出 900 kcal | 标准份为 326 kcal，两条路径均需改进 |
| H05 Mee Siam | 只计入 18 g 豆芽 | 4.32 kcal，对照 562 kcal |
| H06 Mee Rebus | 匹配了少量配料，面和浓汁仍待核对 | 46.72 kcal，对照 559 kcal |
| H08 迷你蛋挞 | 描述里出现了三种蛋挞，未能只处理指定的 A | 无小计 |
| H10 萝卜糕 | 部分重量匹配成了白吐司 | 即使热量碰巧接近，也有食物身份错误 |
| H12 烧卖、H13 炸春卷 | 模型已给出可读菜名，查表均未命中 | 两张都需要人工选项 |
| P05 蓝莓谷物 | 只计 4 g 蓝莓干 | 12.68 kcal，对照标签 111.4 kcal |
| P07 颗粒花生酱、P14 高达奶酪 | 返回了明确的品类名称，没有匹配条目 | 已提供食用量仍然没有营养数值 |
| P13 巧克力豆饼干 | 只计巧克力豆 | 19.2 kcal，对照 171 kcal |

**下一版优先级。** 用独立开发照片修正中英文菜名、括号描述与熟度/做法的匹配；针对只命中配菜的整餐，先请求补全主食或主菜；包装食品增加拍营养标签并按实吃克数换算的流程。保留这批结果作为基线。若使用本批具体失败调参，下一次泛化评测应使用新照片。用户实际纠正所需时间、纠正后的误差和真实摊位逐盘称重仍待评估。

## 重放

记录表保存每张输入的 SHA-256 与参考来源。仓库仅发布来源链接、标签数值和计算结果。用项目 Python 3.12 环境及 pypdf 7.2、Pillow 13.0 可以按原图重建输入。以下命令从仓库根目录运行，第二条会使用团队 API。沿用同一 ledger 目录时会跳过已发起的请求。

```sh
python -m evaluation.paired_images IMAGE_DIR
python -m evaluation.paired_run IMAGE_DIR LEDGER_DIR
python -m evaluation.paired_score LEDGER_DIR
```
